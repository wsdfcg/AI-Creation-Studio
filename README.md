# AI-Creation-Studio · AI 创作工作室

AI 短剧《黎明之前》（改编小说《无声接棒》）的生产资料库 + 考据参考库 + 小说创作库。

## 仓库结构

```
AI-Creation-Studio/
├── README.md                    ← 本文件（索引）
├── 01_考据参考库/               ← 时代考据素材（自传/建筑/影像/影视/机构沿革）
│   └── 1945上海_民国谍战/       ← 按"时代·地域·题材"分档
│       ├── 考据素材清单_v1.md
│       └── （考据锚点陆续沉淀）
└── 02_小说创作/                 ← AI 写小说区
    └── 《无声接棒》/            ← 每部小说一个子目录
        └── （小说原文/大纲/人物设定）
```

## 分区说明

| 分区 | 放什么 | 谁用 |
|---|---|---|
| **01_考据参考库** | 人物自传、建筑专著、时代影像、影视参考、机构沿革——按"时代·地域·题材"分档沉淀 | 短剧/小说开新项目时查时代考据 |
| **02_小说创作** | 小说原文、分集大纲、人物设定、创作素材 | AI 写小说 |

## 考据库使用规则

- 新剧本/新小说开工 → 查本库有没有同时代条目 → 有则引用+按项目补充，没有则跑时代考据 SOP（world-building §2.5）新建时代文件夹
- 只存"已联网核验"的条目（带出处），不许存拍脑袋的
- 每个时代文件夹配一个考据锚点.md，直接给场景卡/角色卡用
