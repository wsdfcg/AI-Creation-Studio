## §2 场景卡锚点

### 2.1 译电房（军统电讯/译电场景）

| 锚点 | 考据结论（可写进场景DNA） | 来源 |
|---|---|---|
| **核心设备** | 收发报机：**45.5×26.5×22cm 方正黑色"铁盒子"**（秦鸿钧烈士机实物尺寸） | 清单 §9.2 |
| **设备型号** | 美国斐尔可 FILCO 发报机（带设置索引表）、德国布朗斯 12 型军用电台、马可尼式发信机+控制桌 | 清单 §9.2 |
| **桌案陈设** | 密电码本（数字密码，先减后翻）、电报原稿、木桌、台灯（夜景办公） | 清单 §9.2 / §1.3 |
| **机构归属** | 军统局本部第四处=电讯处；译电科→机要组（科长姜毅英）；上海办事处电讯组 | 清单 §3.6 / §5.1 |
| **工作氛围** | 昏暗+台灯（视觉风格圣经已定低调照明）；密码本保密严格（"密本股设在乡下防轰炸"） | 清单 §1.3 / §9.2 |
| **时间标记** | 1945.9.8 军统上海办事处成立（杜美路70号），京沪肃奸接收期 | 清单 §5.1 |

### 2.2 石库门（沈砚秋宿舍/住所）

| 锚点 | 考据结论（可写进场景DNA） | 来源 |
|---|---|---|
| **整体格局** | 中等石库门：底楼一层两间+中间正厅+前天井+侧面厢房约20平；正厅后楼梯；二楼一正间一厢房；晒台晾衣 | 清单 §2.3 邹逸麟 |
| **卫生** | **无卫生设备，各自安设马桶**；清晨倒马桶文化；冬天去混堂（公共浴室） | 清单 §2.3 |
| **厨房** | 灶披间 10 余平米放六七只煤球炉，分灶吃饭 | 清单 §2.3 |
| **结构件** | 黑漆大门、门楣砖雕字、小天井、老虎窗、亭子间 | 清单 §2.3 |
| **改造现象** | 二房东把三层楼改六层、客堂改二三间、晒台改房间（"亭子间嫂嫂""灶披间阿姨"） | 清单 §2.3 |
| **生活气息** | "万国旗"晾衣杆、煤球炉、弄堂推桥人/叫卖声（参考舞剧《永不消逝的电波》） | 清单 §4.2 |

> ⚠️ 尺寸依据：**无独用卫生间/浴室**——沈砚秋住所场景里不许出现独立浴室（穿帮高发点）。

### 2.3 苏州河

| 锚点 | 考据结论（可写进场景DNA） | 来源 |
|---|---|---|
| **1945 实景** | 河道塞满船只（帆船/驳船）、**水质黑臭污染严重**（不是绿水） | 清单 §9.1 |
| **天际线** | 1945.9.8 航拍：百老汇大厦（楼面有日军强改"兴亚"字样）、外滩公园、新天安堂、邮政总局、新亚大酒店尖塔；虹口无高楼 | 清单 §9.1 |

| **桥（过桥戏）** | 外白渡桥（1908 钢桥）、乍浦路桥（1927 钢筋混凝土，铁艺栏杆）、西藏路桥（"新垃圾桥"）、浙江路桥 | 清单 §9.1 / §3.5 |
| **雨夜/街头** | 1946 乍浦路桥实拍：老虎塌车上桥走"之"字、桥头推桥人收三分五分 | 清单 §9.1 |
| **交通** | 黄包车、电车（有民国《上海市街图》带电车线路）、自行车、步行 | 清单 §3.4 |
